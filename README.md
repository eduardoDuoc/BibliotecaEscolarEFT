# 📚 Sistema de Gestión de Biblioteca Escolar

## Descripción

Este proyecto consiste en una aplicación de escritorio desarrollada en Java para facilitar la administración de una biblioteca escolar.

El sistema permite gestionar libros, estudiantes, préstamos y devoluciones, manteniendo la información organizada y almacenada en una base de datos.

## Funcionalidades principales

- **Inicio de sesión:** acceso al sistema mediante usuarios registrados.
- **Gestión de libros:** registrar, consultar, editar y eliminar libros.
- **Gestión de estudiantes:** administrar los datos de los estudiantes.
- **Préstamos y devoluciones:** registrar movimientos y actualizar automáticamente el stock disponible.
- **Control de atrasos:** identificar libros que no han sido devueltos dentro del plazo establecido.
- **Reportes:** consultar los libros más prestados, préstamos activos e historial de estudiantes.

## Herramientas utilizadas

- Java
- IntelliJ IDEA
- Java Swing (interfaz gráfica)
- MySQL y MySQL Workbench
- JDBC (conexión a base de datos)

## Funcionamiento

La aplicación cuenta con ventanas que permiten realizar las distintas operaciones de forma sencilla. Los cambios realizados se almacenan en MySQL para mantener actualizada la información de la biblioteca.

Para utilizar el proyecto es necesario contar con Java y una base de datos MySQL configurada.
